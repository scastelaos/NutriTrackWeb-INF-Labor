# NutriTrackWeb-INF-Labor

INF-Labor Project: NutriTrackWeb - Nutritionist Management Platform.

## NutriTrackWeb

NutriTrackWeb ist eine Webplattform für selbstständige Ernährungsberaterinnen zur Verwaltung von Kunden, Terminen, Dokumenten, Mahlzeitenfotos, Zahlungen und Kommunikation.
